# Lock Compact Mode Button

Zen ships the compact mode button as a normal toolbar widget, so Customize mode can drag it off the sidebar, and a narrow sidebar can move it into the overflow panel. This mod sets `removable` and `overflows` to `false` on that button, the same pair the workspaces button already uses.

If the button is missing from every toolbar, it is placed back at the start of the sidebar's top button row. A button you moved to another toolbar stays where you put it, and just can no longer be removed.

On Windows the sidebar's minimum width is 50px wider than Zen's own floor, so that row of buttons stays inside the sidebar instead of painting over the page.

## Install

1. Install [Sine](https://github.com/CosmoCreeper/Sine) if you don't already have it.
2. Open **Settings → Sine Mods**.
3. Install from this repository, or point Sine at a local copy of this folder.
