# Lock Compact Mode Button

Zen ships the compact mode button as a normal toolbar widget, so Customize mode can drag it off the sidebar. This mod sets `removable` to `false` on that button, the same lock the workspaces button already uses.

If the button is missing from every toolbar, it is placed back at the start of the sidebar's top button row. A button you moved to another toolbar stays where you put it, and just can no longer be removed.

## Install

1. Install [Sine](https://github.com/CosmoCreeper/Sine) if you don't already have it.
2. Open **Settings → Sine Mods**.
3. Install from this repository, or point Sine at a local copy of this folder.
